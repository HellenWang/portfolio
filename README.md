# Harley — Portfolio & Blog

> Cloud-Native Engineer & Web Developer | Ex-Alibaba Cloud Tech Lead

Bilingual (EN/ZH) portfolio and blog built with AstroPaper.

## Tech Stack

- **Framework**: Astro v7
- **Styling**: TailwindCSS v4
- **Content**: Markdown + MDX
- **i18n**: Built-in Astro i18n (English + Chinese)
- **Search**: Pagefind
- **Deploy**: GitHub Pages

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
